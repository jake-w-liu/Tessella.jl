Tessella.API.onelab

Tessella.API.onelab — Module
onelab

Session ONELAB parameter store (Gmsh 4.15.2 onelab module counterpart). set/get exchange the parameter space as a JSON array of records carrying "type" ("number"/"string"), "name", "values" and the optional "min"/"max"/"step"/"choices"/"valueLabels"/"attributes"/ "label"/"shortHelp"/"longHelp"/"readOnly"/"visible"/"closed"/ "kind" members; get_names lists names matching a */? glob. set_number/set_string and get_number/get_string are the typed value endpoints. clear removes matching parameters (all when empty); set_changed/get_changed/clear_changed expose the changed-name flags a solver client would poll, and .geo DefineNumber/SetNumber/GetNumber (and the string forms) exchange with this store through open/merge/ open_geo!. run launches a named native ONELAB socket client, waits for its process and nested clients, and closes the owned process tree and sockets on completion or failure. With no arguments it runs the registered clients.

Tessella.API.onelab.run — Function
run(name="", command=""; timeout=Inf, connect_timeout=60,
    max_message_bytes=64*1024*1024, max_clients=32)

Run a native ONELAB client process. The command receives -onelab name 127.0.0.1:port; a later call with just name reuses its registered command. The optional limits bound elapsed time, connection startup, queued frame bytes and simultaneous clients. An empty registry makes run() a no-op.
