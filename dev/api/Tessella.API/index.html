Tessella.API

Tessella.API — Module
API

Gmsh-style model/mesh/option façade over Tessella's native kernels, including deterministic entity-topology, analytical spatial, native type/partition metadata, native Point/Line/Plane evaluation and reparametrization, entity presentation and attribute state, finite Point-coordinate updates, and Physical-group queries, entity-name, atomic-tag, and dependency-safe removal mutations, Physical-group mutations, point-local mesh-size constraints, explicit planar surface-loop volumes, operation-time Boolean operand ownership, and persistent affine relations between straight or curved periodic boundary or embedded curves and planar periodic volume boundaries. The session owns atomic uniform refinement, affine coordinate transformation, complete clearing, and detached Gmsh-shaped bulk node/element retrieval for its linear-simplex mesh cache, plus deterministic global edge and triangular or quadrangular face catalogs, fixed-family actual- and explicit-order nodal reference functions, order-one H1 bases over simplex, Point, Quadrangle, Hexahedron, and Prism reference families with lowest-order H(curl) bases over simplexes, orientations, and node/edge keys. It also owns a reusable robust AABB locator for dense element-by-coordinate and reference-coordinate queries, plus scale-robust named quality queries and Gmsh-shaped forward maps/Jacobians over dense cached elements. Element type/property lookup and bounded fixed-family reference quadrature are available without a session. Production meshing is never delegated to Gmsh.

An ONELAB solver client connected to a parameter server over TCP — the client half of the documented upstream socket protocol. Construct with API.onelab.client_connect; close with API.onelab.client_disconnect.

Tessella.API.merge — Method
merge(filename::AbstractString)

Merge a .geo, .msh, .unv, .mesh, .meshb, .stl, .su2, .bdf, .nas, .inp, .neu, .p3d, .mail, .ir3, .diff, .vtk, .wrl, .off, .obj, .ply, .ply2, .step, .stp, .igs, .iges, .brep, .xao or supported .pos list file atomically. Existing models, the current model slot, associated filename and held views survive. GEO executes against current entities, fields and options; an explicit SetName is honored. Supported literal MSH identities/periodic/partition/data metadata are retained; duplicate UID occurrences or incompatible partition namespaces reject before publication. STL welds through read_stl and lands on the lowest free discrete Surface tag. STEP, IGES, BREP and XAO files add their actual native CAD entities while retaining the current slot, mesh, fields and held views. Explicit external GEO actions are outside the rollback contract. POS adds list views only, leaving the current model and associated filename unchanged.

Tessella.API.open — Method
open(filename)

Import a .geo, .msh, .unv, .mesh, .meshb, .stl, .su2, .bdf, .nas, .inp, .neu, .p3d, .mail, .ir3, .diff, .vtk, .wrl, .off, .obj, .ply, .ply2, .step, .stp, .igs, .iges, .brep, .xao or supported .pos list file into a new current model, reusing an empty current model. Nonempty prior models and session views remain alive. MSH imports keep actual UIDs, entity ownership and retained metadata; UNV and Medit/MESH imports (ASCII .mesh and binary .meshb alike) publish through the same channel with their elementary and physical tags mapped to entity ownership, as do SU2 markers (mapped to physical groups and names), Nastran property ids (mapped to elementary entity and physical tags), Abaqus element sets (mapped to elementary and physical tags plus physical names), Gambit element groups/boundary sets (mapped the same way) and PLOT3D structured blocks (mapped to per-dimension entities carrying quads or hexes); MAIL imports publish their triangles on one implicit surface and IR3 imports publish their self-describing element records on the tag-column entities; DIFF imports publish their subdomain-column records on per-subdomain entities like the pinned reader; VTK imports publish unstructured-grid/polydata cells on per-dimension entities like upstream; WRL imports publish VRML 1.0/2.0 IndexedFaceSet/IndexedLineSet coordIndex geometry through read_wrl on per-set curve/surface entities like the pinned reader, STEP, IGES and BREP imports synchronize actual native CAD entities through the same importer as model.occ.import_shapes. XAO imports bind the real BREP topology, entity names and physical groups, including separately stored BREP shapes. Unsupported CAD records retain the native reader's diagnostics. STL imports weld through read_stl and publish one discrete Surface; ordinary model data sections create views bound to the imported model. The model name is the filename stem unless GEO SetName supplies one. Failed preparation leaves model slots, caches, options and views unchanged; this stricter failure contract differs from Gmsh's missing-file partial publication. POS imports preserve named list views, time values, text, interpolation schemes and supported higher-order list records.

Tessella.API.open_geo! — Method
open_geo!(path; mesh_dim=0)

Execute a bounded .geo file into the initialized API session. Stored model and mesh state are detached from the returned execution result. Accepted syntax and blockers follow Tessella.GeoExec.execute_geo. Successful execution replaces the current model's contents; failed preparation leaves session state unchanged.

Tessella.API.option — Method
option(name) -> Float64
option(name, value) -> Float64

Get or set one supported process-global option in an initialized session. MeshSizeMin is nonnegative; MeshSizeMax, MeshSizeFactor, and its alias CharacteristicLengthFactor (one upstream lcFactor value) are positive; the minimum may not exceed the maximum. Mesh.TransfiniteTri is 0 or 1 and selects the three-sided transfinite surface algorithm. Mesh.FlexibleTransfinite, Mesh.RecombineAll, and Mesh.MeshSizeExtendFromBoundary store truncated integer flags. Mesh.RecombinationAlgorithm truncates to 0–4 (out-of-range resets to 0). Geometry.OldRuledSurface selects the legacy triangular ruled evaluator for geometry and computed native node-parameter queries. The mesh options feed meshing policies at generate time. Boolean and nonfinite values are rejected, and a failed update leaves all options unchanged.

Tessella.API.write — Method
write(filename)

Write the current model's actual mesh to a .msh, .msh2, .msh22, .msh4, .msh41, .stl, .unv, .mesh, .meshb, .su2, .bdf, .nas, .inp, .neu, .p3d, .mail, .ir3, .diff or .vtk file. .msh uses Mesh.MshFileVersion to select 2.2 or 4.1 while the versioned aliases force the corresponding dialect; .msh1, .msh3 and .msh40 reject. Mesh.Binary selects the encoding, and Mesh.SaveAll controls physical selection for MSH and the foreign formats. .stl writes ASCII or binary surface facets according to Mesh.Binary (quads split on the first-third vertex diagonal) and rejects volume elements; MSH4 preserves actual UIDs and retained periodic, partition, ghost, and data metadata; MSH2 uses its native dense numbering. .unv emits I-DEAS datasets 2411/2412 with elementary and physical tags; .mesh emits INRIA/Medit sections with ref carrying the physical tag (or entity tag when no physical tag is set); .meshb emits the same sections in the libMeshb binary (GMF keyword) encoding; .su2 emits NDIME/NPOIN/NELEM with physical groups as named MARKER sections; .bdf/.nas emit Nastran GRID and element cards with the physical tag in the property-id field; .inp emits Abaqus *NODE/*ELEMENT blocks plus *ELSET/*NSET physical sections (entity sets use the Volume|Surface|Line|Point<tag> convention); .neu emits a Gambit neutral deck with ELEMENT GROUP sections per top-dim physical tag and BOUNDARY CONDITIONS sections resolved from dim-1 physical cells; .mail emits the CEA triangulation deck (nv nt header, %19.10E vertex rows, dense index triples and 0 0 0 edge placeholders) keeping only triangle cells; .ir3 emits the Iridium deck (33 format line, numVertices num2D num3D header, %.16g vertex rows and self-describing num tag numVert records with per-dimension numbering) whose tag field carries the elementary entity tag (the upstream Mesh.SaveElementTagType default; IO.write_ir3 also honors values 1–3); .diff emits the Diffpack/GridFE deck (counted banner, [k]-tagged node rows, top-dimension Elm* records whose subdomain column is each entity's physical tag set — one record per membership — or the entity tag when no physical groups exist); .vtk emits a legacy ASCII unstructured grid (POINTS/CELLS/CELL_TYPES, physical tags as a CellEntityIds scalar section when present) with the lattice-verified VTK node orderings the model-view writer uses; .p3d writes only entities with structured transfinite grids upstream, so every export rejects with "no structured grids to save". The foreign formats retain neither partitions, periodic links nor data sections; .su2, .inp and .neu retain physical names. Unsupported metadata/format combinations reject before replacing the target. The model, mesh cache, views, counters, and model filename remain unchanged.
