Tessella.HighOrder

Tessella.HighOrder — Module
HighOrder

High-order (curved) elements. This module generates quadratic (10-node, P2) tetrahedra from a linear tet Mesh by adding one shared node at the midpoint of every edge, in Gmsh's type-11 node order (4 corners, then the 6 edge nodes on edges (1,2),(2,3),(3,1),(1,4),(3,4),(2,4)). The same construction lifts linear triangles to quadratic (6-node, P2) triangles in Gmsh's type-9 order (3 corners, then edge nodes on (1,2), (2,3), (3,1)), certified by the exact degree-4 Bernstein bound of the Gram determinant |∂x/∂r × ∂x/∂s|², and linear segments to quadratic (3-node, P2) segments in Gmsh's type-8 order (endpoints, then the mid-node), certified by the exact degree-2 Bernstein bound of the squared speed |∂x/∂ξ|² on [-1,1].

Edge nodes use the correctly rounded Float64 midpoint. When the mathematical average is representable, straight-sided P2 is geometrically identical to the linear mesh; p2_volume always measures the actual stored isoparametric mapping. curve_to_cylinder! / curve_to_surface! then curve edge nodes onto the true boundary geometry for curved-boundary accuracy.

Curving is done safely: only mid-nodes on genuine boundary-surface edges are moved (never interior chords — moving those tangles the volume), and every projection is reverted unless every incident element has a strictly positive exact cubic-Bernstein Jacobian certificate over the whole reference tetrahedron. Thus a between-sample fold cannot pass the guard.

The same exact-Bernstein certification is extended to the curved non-simplex reference families by p2_quad_min_jacobian (gmsh type-10 9-node quadrangle, degree-(6,6) tensor-Bernstein bound of the Gram determinant |∂x/∂u × ∂x/∂v|²), p2_hex_min_jacobian (gmsh type-12 27-node hexahedron, degree-(5,5,5) bound of det ∂x/∂(u,v,w)) and p2_prism_min_jacobian (gmsh type-13 18-node prism, triangle-degree-4 × line-degree-5 product-Bernstein bound of the same signed determinant).

Tessella.HighOrder._P2ParametricSupport — Type

Parametric support of a certified-P2 node that must stay on its owning CAD entity instead of moving freely in space — the descriptor sliders maps carry in optimize_p2_interior!.

  • u: current parameter values ([u] for curve-owned nodes, [u,v] for surface-owned nodes). Replaced — never mutated in place — by an accepted candidate so a rejected pass leaves the stored state untouched.
  • lift: lift(u::Vector{Float64}) -> NTuple{3,Float64} re-evaluates the owning entity at candidate parameters; it must be the same evaluator that produced the node's stored coordinates.
  • lower, upper: per-coordinate parameter bounds; probes and candidates are clamped to this box so a node can never leave its entity's range.

Tessella.HighOrder.curve_to_curve! — Method
curve_to_curve!(p::P2SegMesh, project, on_curve; rtol=1e-6)

Curve quadratic-segment mid-nodes onto a curve: project(x,y,z) snaps a point and on_curve(x,y,z) gates on the two endpoints. Any projection whose element loses the exact global positive-speed certificate is reverted, so the mesh never gains a folded element. Deterministic (segments processed in ascending mid-node id order). Returns the number of nodes actually moved by more than rtol·bbox-diagonal.

Tessella.HighOrder.curve_to_cylinder! — Method
curve_to_cylinder!(p::P2Mesh, center, axis, radius; rtol=1e-6) -> n_curved

Curve the quadratic mesh onto a cylinder of the given center, axis, radius: every boundary-surface edge whose both corner endpoints lie on the lateral wall (radial distance radius from the axis, within rtol) has its mid-node projected radially onto the exact cylinder — turning the straight chord into a true curved P2 edge. Interior chords are never touched, and any projection that would invert an incident element is reverted (see module docstring). Flat caps and axial spokes stay straight. Returns the number of mid-nodes moved.

Tessella.HighOrder.curve_to_surface! — Method
curve_to_surface!(p::P2Mesh, project, on_surface; rtol=1e-6) -> n_curved

Curve the quadratic mesh onto an arbitrary target surface — the general form of curve_to_cylinder!. project(x,y,z) -> (x,y,z) snaps a point onto the surface; on_surface(x,y,z) -> Bool tests whether a corner lies on it. A mid-node is curved only when it sits on a genuine boundary-surface edge and both its corner endpoints satisfy on_surface — interior chords (whose endpoints may also lie on the surface) are never moved. Any projection that would invert an incident element, or that returns a non-finite point, is reverted, so the result never contains an inverted element. Returns the number of mid-nodes actually moved (displacement > rtol × bounding-box diagonal).

Tessella.HighOrder.curve_to_surface! — Method
curve_to_surface!(p::P2TriMesh, project, on_surface; rtol=1e-6)

Curve quadratic-triangle edge nodes onto a surface: project(x,y,z) snaps a point and on_surface(x,y,z) gates on the two corner endpoints. Every edge of a surface triangle lies on the surface, so every qualifying mid-node is moved — including interior edges, whose midpoint is off a genuinely curved surface. Any projection whose incident elements lose the exact global positive Gram-determinant certificate is reverted, so the mesh never gains a folded element. Deterministic (mid-nodes processed in ascending id order). Returns the number of nodes actually moved by more than rtol·bbox-diagonal.

Tessella.HighOrder.optimize_p2_interior! — Method
optimize_p2_interior!(coords, blocks, movable;
    itermax=100, passes=25, fraction=0.2, hmin_fraction=1e-3,
    tolerance=1e-10, fixed_edges=nothing, fixed_facets=nothing,
    sliders=nothing, threshold_min=-Inf, threshold_max=Inf)
    -> (moved, min_before, min_after, sweeps, evals)

Bounded relocation pass for the interior high-order nodes of the certified quadratic families (gmsh types 9, 10, 11, 12, 13) — the Mesh.HighOrderOptimize=1 engine. coords is the shared 3 × nnodes Float64 matrix updated in place; blocks is an iterable of (msh_type, connectivity) pairs covering the blocks that share coords (certified families are optimized; every other block only excludes the nodes it references); movable is a length-nnodes boolean mask additionally restricting candidates — a node moves only when it is marked movable, is referenced exclusively through high-order slots of a single certified family (never as a corner of any element, never by an uncertified block), and its support is interior to the family complex: mid-edge nodes need a primary edge touching no boundary facet (and only volume-family edge mids are eligible — surface edge mids support the CAD surface even on interior wire edges), face-center nodes an interior primary face, and element-interior nodes are always eligible. fixed_edges/fixed_facets may pass extra undirected primary-edge pairs and sorted facet tuples whose mids must also stay fixed — the API layer uses them for owner-group interfaces that are internal to the combined complex but still carry surface-projected supports.

sliders optionally maps a node index (Int32) to a _P2ParametricSupport describing the node's owning-entity parametrization. A slider node is a candidate even when movable marks it fixed: instead of free-space relocation it performs the same bounded ascent in parameter space (_p2_opt_slide!), generating candidate coordinates by re-evaluating lift(u) inside [lower, upper], so the node stays exactly on its CAD entity. Sliders bypass the boundary-edge/facet support checks — the caller's classification asserts the entity ownership — but stay blocked as corners, cross-family or multi-role nodes, and by references from uncertified blocks other than 1-D cell blocks (a Seg3 block discretizing the same owning curve shares the node's parameter state rather than conflicting with it). An accepted move replaces support.u; a rejected one restores the stored coordinates bit-for-bit and leaves support.u untouched.

Each node performs a bounded ascent on the minimum scaled Jacobian measure of its incident elements — det J/(|c1|·|c2|·|c3|) for volume families, |c1×c2|/(|c1|·|c2|) for surface families — sampled at the family's interpolation points. A candidate position is kept only when the exact Bernstein certificate stays positive on every touched element and the sampled minimum strictly improves; otherwise the node is restored bit-for-bit. Elements entering the pass without a positive certificate can never accept a candidate, so the pass neither creates nor repairs inverted elements. itermax bounds the per-node descent steps, passes bounds global sweeps (a sweep without any accepted move stops early), fraction sets the initial step as a fraction of the supporting length, hmin_fraction stops the descent below that fraction, and tolerance is the strict improvement threshold. threshold_min/threshold_max bound the optimization band: a node is only a candidate when its incident minimum lies inside [threshold_min, threshold_max) — mirroring upstream Mesh.HighOrderThresholdMin/Max. Returns the number of moved nodes, the global sampled minimum before/after over all certified blocks, the number of sweeps performed, and the count of candidate evaluations.

Tessella.HighOrder.p2_hex_min_jacobian — Method
p2_hex_min_jacobian(coords, hex27) -> Float64

Minimum exact degree-(5,5,5) tensor-Bernstein coefficient of the quadratic-hexahedron isoparametric Jacobian determinant det ∂x/∂(u,v,w) over all elements, returned as Float64. coords is a 3 × nnodes real coordinate matrix and hex27 is a 27 × nhexes integer connectivity matrix in gmsh type-12 order (corners, edge mids, face centers, body center — the lagrange_nodes(12) layout). It is a conservative global lower bound: > 0 formally certifies every element over the whole closed reference cube [-1,1]³; ≤ 0 means the batch is not certified (and may be folded). For a straight-sided parallelepiped element this equals volume/8 > 0.

Tessella.HighOrder.p2_prism_min_jacobian — Method
p2_prism_min_jacobian(coords, pri18) -> Float64

Minimum exact triangle-degree-4 × line-degree-5 product-Bernstein coefficient of the quadratic-prism isoparametric Jacobian determinant det ∂x/∂(r,s,w) over all elements, returned as Float64. coords is a 3 × nnodes real coordinate matrix and pri18 is a 18 × nprisms integer connectivity matrix in gmsh type-13 order (corners, edge mids, quadrilateral face centers — the lagrange_nodes(13) layout). It is a conservative global lower bound: > 0 formally certifies every element over the whole closed reference prism {r,s ≥ 0, r+s ≤ 1} × [-1,1]; ≤ 0 means the batch is not certified (and may be folded). Tessella.HighOrder.p2_quad_min_jacobian — Method
p2_quad_min_jacobian(coords, quad9) -> Float64

Minimum exact degree-(6,6) tensor-Bernstein coefficient of the quadratic-quadrangle Gram determinant g = |∂x/∂u × ∂x/∂v|² over all elements, returned as Float64. coords is a 3 × nnodes real coordinate matrix and quad9 is a 9 × nquads integer connectivity matrix in gmsh type-10 order (corners, then the edge mids on (1,2),(2,3),(3,4),(4,1), then the face center — the lagrange_nodes(10) layout). It is a conservative global lower bound: > 0 formally certifies every element is a regular surface map over the whole closed reference square [-1,1]²; ≤ 0 means the batch is not certified (and may be folded or degenerate). For a planar parallelogram element this equals (area/4)² > 0.

Tessella.HighOrder.p2_seg_length — Method
p2_seg_length(p::P2SegMesh) -> Float64

Total isoparametric length of a quadratic segment mesh, measured by a fixed order-16 Gauss rule on ξ ∈ [-1,1]. Every element first has to pass the exact global positive-speed certificate. The integrand |∂x/∂ξ| is a square root of a degree-2 polynomial, so the value is a high-order quadrature estimate, not an exact integral — use p2_seg_min_jacobian for the certified bound. For a straight-sided P2 segment this reduces to its linear endpoint-chord length.

p2_seg_min_jacobian(p::P2SegMesh) -> Float64

For a straight-sided P2 segment this equals (length/2)² > 0.

Tessella.HighOrder.p2_volume — Method

Total isoparametric volume of a P2 mesh. The P2 Jacobian determinant is cubic, so its exact cubic Bernstein coefficients integrate to their sum divided by 120. Every element first has to pass the exact global Bernstein positivity certificate; the positive coefficients are then accumulated with 256-bit arithmetic before the single Float64 result conversion. A folded element cannot be hidden by absolute values or sampled quadrature. For a straight-sided P2 tet this reduces to its linear corner-tet volume.
