Tessella.API.view

Tessella.API.view — Module

Session post-processing views (see the Gmsh 4.15.2 view module).

source
Tessella.API.view.add — Function

Add a new empty view named name, returning its tag.

source
Tessella.API.view.add_alias — Function

Add a view as an alias of refTag: data is shared with the reference view while options stay per-view (copied when copyOptions is set). A positive tag replaces the view registered under it. Returns the tag.

source
Tessella.API.view.add_homogeneous_model_data — Function

Add homogeneous (flat-row) model data for tags on modelName at step — the flat counterpart of add_model_data.

source
Tessella.API.view.add_list_data — Method

Add per-element list data of data_type for numEle elements.

source
Tessella.API.view.add_list_data_string — Function

Attach per-element label data strings with 3-D coord anchors to view tag under data_type (numEle defaults to length(data)).

source
Tessella.API.view.add_model_data — Function

Add per-entity data of data_type at step to view tag.

source
Tessella.API.view.combine — Function

Combine the elements or steps of all views (how="all"), visible views ("visible") or same-named views ("name") into new views; remove the originals when remove is set and copy the first member's options when copy_options is set.

source
Tessella.API.view.copy_options — Method

Copy the numeric and string options of view refTag onto tag.

source
Tessella.API.view.get_color — Method

Return color option name of view tag as (r, g, b, a).

source
Tessella.API.view.get_homogeneous_model_data — Method

Return (dataType, tags, data) for view tag at step, restricted to rows owned by modelName.

source
Tessella.API.view.get_index — Method

Return the index of view tag in the view list, or -1.

source
Tessella.API.view.get_list_data — Function

Return the list data types and data of view tag.

source
Tessella.API.view.get_list_data_strings — Function

Return the string list block holding numEle elements as (dataType, data) — plus coord when return_coord is set.

source
Tessella.API.view.get_model_data — Method

Return the model data types, entity tags, and values of view tag at step.

source
Tessella.API.view.get_number — Method

Return numeric option name of view tag (0 if unset).

source
Tessella.API.view.get_string — Method

Return string option name of view tag (empty if unset).

source
Tessella.API.view.get_tags — Method

Return the tags of all views, in increasing tag order.

source
Tessella.API.view.probe — Function

Return (values, distance) from a list or model view. step=-1 samples all steps; gradient=true returns physical component gradients. Exact matches are preferred; nonzero distance_max enables nearest-node fallback. Model queries over all steps follow the first frame's material element coordinates.

source
Tessella.API.view.probe — Method

Sample model view tag at step 0 on modelName, using its complete geometry and nodal basis. Returns the component vector.

source
Tessella.API.view.remove — Method

Remove the view with tag tag.

source
Tessella.API.view.set_color — Function

Set color option name of view tag to the packed rgba components.

source
Tessella.API.view.set_interpolation_matrices — Function

Store d field interpolation basis coefficients/exponents (and dGeo geometry interpolation when positive) for the element family type on view tag. d <= 0 removes the family's matrices.

source
Tessella.API.view.set_number — Method

Set numeric option name of view tag to value.

source
Tessella.API.view.set_string — Method

Set string option name of view tag to value.

source
Tessella.API.view.set_visibility_per_window — Function

Record visibility flag value for windowIndex on view tag.

source
Tessella.API.view.write — Function

Write list or model view data using the filename's supported export format.
