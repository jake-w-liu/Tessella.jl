Tessella.BRep

Tessella.BRep — Module
BRep

Native ISO-10303-21 STEP and IGES CAD import. Solids that classify as an axis-aligned block, sphere, right circular cylinder, right circular cone, or torus are converted to Tessella surfaces and filled. Closed-shell MANIFOLD_SOLID_BREP/FACETED_BREP/BREP_WITH_VOIDS topology bounded by planar faces over straight edges imports as the exact polygonal boundary; a single unbounded TOROIDAL_SURFACE face imports as a parametric torus boundary, a single SPHERICAL_SURFACE face whose boundary loops collapse onto the two poles imports as a full sphere, a three-face shell whose CYLINDRICAL_SURFACE lateral face binds two certified rim circles with matching PLANE caps imports as a full cylinder, a CONICAL_SURFACE lateral face whose certified rim circles (and apex, for a full cone) are closed by PLANE caps imports as a full cone or frustum, and a TOROIDAL_SURFACE lateral face bounded by two meridian rim circles closed by PLANE caps imports as a partial-angle torus segment whose cap face orientations select the materialized sweep. IGES solids bounded by trimmed plane surfaces over line edges (144→142/141→102/110 or the 186/514/510/508/504/502 MSBO chain) and IGES 160/198 tori take the same paths. NURBS curves and surfaces (STEP B_SPLINE_* / IGES 126/128) import as NURBSCurve / NURBSSurface. Unrecognized topology is an explicit blocker, not a silent empty mesh.

Tessella.BRep.export_iges_nurbs — Method
export_iges_nurbs(path, objects) -> path

Validate and atomically write a nonempty collection of native NURBS curves and surfaces as IGES type 126/128 parameter records. Each surface receives an untrimmed type-144 wrapper so CAD readers expose it as a topological face. Unsupported objects are rejected before the destination is replaced.

Tessella.BRep.import_iges — Method
import_iges(path; fill=true) -> Mesh or MixedMesh

Import one classified IGES solid: a type 150 Block, type 158 Sphere, the supported type 156 Cylinder/Cone layouts, a type 160/198 torus, a full-torus type 120 Surface of Revolution (full-circle generatrix in an axial plane, full 2π sweep — the OCC export layout), or a closed-shell polyhedron bounded by trimmed planar faces over line edges — either through type 143 bounded or type 144 trimmed surfaces on type 108/190 planes with 142/141→102/110 boundaries, or through the type 186/514/510/508/504/502 manifold-solid chain. fill=true returns a validated tetrahedral mesh and fill=false returns the closed triangle boundary. Multiple independent source solids with distinct positive directory-entry identities return a classified MixedMesh, with one discrete closed-shell Surface and Region per source solid. Strictly disjoint bounding boxes certify separation; touching/overlapping boxes are unsupported. This mesh import does not reconstruct analytic CAD wires. Nonplanar/nonlinear face topology, and files without a recognized solid are explicit blockers. Use import_nurbs_iges for IGES 126/128 entities.

Tessella.BRep.import_nurbs_iges — Method
import_nurbs_iges(path) -> Vector

Import all supported IGES type 126 B-spline curves and type 128 tensor-product B-spline surfaces as native NURBS objects. Record counts, finite numeric data, and allocation bounds are checked before arrays are allocated.

Tessella.BRep.import_nurbs_step — Method
import_nurbs_step(path) -> Vector

Import supported STEP B_SPLINE_CURVE_WITH_KNOTS and B_SPLINE_SURFACE_WITH_KNOTS entities as native NURBSCurve and NURBSSurface objects, including supported complex rational curve and surface forms. Returns every recognized object in STEP entity order and blocks when none are present.

Tessella.BRep.import_step — Method
import_step(path; fill=true) -> Mesh or MixedMesh

Import one classified STEP solid: a synthetic axis-aligned eight-corner point block, SPHERE, RIGHT_CIRCULAR_CYLINDER, RIGHT_CIRCULAR_CONE, TOROIDAL_SURFACE, or a MANIFOLD_SOLID_BREP/FACETED_BREP/BREP_WITH_VOIDS closed shell bounded by planar faces over straight edges (a single unbounded TOROIDAL_SURFACE face imports as a full torus, a single SPHERICAL_SURFACE face whose boundary vertices are only the two poles imports as a full sphere, a three-face CYLINDRICAL_SURFACE-plus-caps shell whose rim circles are certified closed imports as a full cylinder, and a CONICAL_SURFACE-plus-caps shell whose rims (and apex) are certified imports as a full cone or frustum; a TOROIDAL_SURFACE-plus-caps shell whose meridian rim circles are certified imports as a partial-angle torus segment). By default the classified boundary is tetrahedralized; fill=false returns its validated closed triangle surface. Multiple explicitly rooted independent solids return a classified MixedMesh, retaining one discrete closed-shell Surface and Region per source solid in source-ID order. Strictly disjoint bounding boxes certify separation; touching/overlapping boxes are an explicit unsupported context. Explicit rigid mapped occurrences through one shape-definition root are supported; see docs/src/reference/step_mapped_occurrences.md for placement and assembly restrictions. Nested NEXT_ASSEMBLY_USAGE_OCCURRENCE product graphs are expanded along every root-to-leaf path of an acyclic product-definition forest; each edge binds its actual parent/child representations, frames and declared unit contexts, physical rigid transforms compose in path order, leaf geometry scales once by its own declared factor, and separate occurrence identities are emitted per path. Every definition — root, intermediate or leaf — may also place its own closed solids and MAPPED_ITEM occurrences; mapped sources carry their own declared unit context and expand transitively under the same coordinate-change law. Ordinary roots, assembly records and the mapped-occurrence producer convert declared SI and CONVERSION_BASED_UNIT length units to millimetres; supported SI prefixes also qualify angular units, and uncertainty measures alias any equivalent unit declaration by resolved factor. This mesh import does not reconstruct analytic CAD Face/Curve parametrization. Nonplanar or nonlinear face geometry, open shells, mixed point-cloud topology, and files without a recognized solid are explicit blockers. Use import_nurbs_step for STEP B-splines.

Tessella.BRep.parse_step_entities — Method
parse_step_entities(source) -> Dict{Int,StepEntity}

Parse the DATA section of an ISO-10303-21 STEP string into entities keyed by their positive STEP identifier. The bounded native parser accepts the scalar, reference, enum, string, nested-list, and complex-entity syntax needed by Tessella's classified primitive and NURBS import paths. Duplicate identifiers, nonfinite numbers, and malformed syntax raise ArgumentError.
