# Rigid periodic boundaries in hybrid Regions

The public mesh API supports one ordinary explicit Region whose current planar
Tri3/Quad4 shell contains quadrangles and one or more independent periodic
Surface pairs whose maps are certified proper rigid transforms. Each slave
Surface carries exactly one master; independent directions (an x/y/z-periodic
box) certify per pair, and a corner vertex where several relations meet binds
a different master under each relation's own affine. Mesh the master Surface
first and let each slave copy it. An explicitly
transfinite slave is meshed independently and does not supply the copy
correspondence required by this hybrid constructor.

Use `API.mesh.set_periodic(2, [slave], [master], affine)` with a row-major 4×4
affine whose linear part is orthonormal with determinant +1 — a pure
translation (identity linear part) or a rigid rotation — and the translation
in the last column.
`API.mesh.generate(3)` preserves the copied boundary node identities and cyclic
cell connectivity while producing positive Tet4 and Pyramid5 cells.
`API.mesh.set_order(2)` retains the linear correspondence and publishes the
quadratic boundary pairs.

The same Region can consume boundaries previously generated by
`API.mesh.generate(2)` with `Mesh.MeshOnlyEmpty=1`: both paired Surfaces must
retain their owned constructors and live published correspondence. Coordinates
verify the recorded identities; they do not select periodic node pairs.

The constructor checks exact lower ownership, complete copied UID coverage,
affine coordinates, ordered Surface cells, exterior incidence, and total signed
volume before publication. A rotated pair also induces Surface-derived
cross-side Curve relations; those ride the existing `derived` provenance
through the owned lower producer while directly declared cross-surface Curve
relations keep their explicit guard. A second master for an already-bound
slave Surface, sheared, reflected, scaled or otherwise non-rigid transforms,
missing or incomplete copy history, and cross-Region boundary pairs remain
outside this admission and are rejected atomically.

A multi-Region hybrid batch can also consume translated Surface pairs
per Region for separate components or connected Regions with literal shared
Tri interfaces. Independent directions on one Region certify per pair; joint
copy events keep one binding per `(slave UID, transform)` so a shared corner
vertex may reach distinct masters under distinct transforms. Both paired Surfaces must be uniquely owned exterior Faces of
that Region. This batch admission uses default `Mesh.OptimizePyramids=0`;
shared periodic Faces and other Pyramid modes remain guarded. The
[connected component scope](shared_periodic_hybrids.md) binds joint copy events. Each pair consumes actual fresh copy events or
retained live published copy history. Every Region is certified before any
volume RNG or factory clock is consumed, after partitioning, and after the
batch's final optimization. No periodic pairs are inferred from coordinates.
Per-Region positive typed cells, exact exterior/UID ownership and analytic
volume certificates remain required.

The bounded regressions are
[`api_periodic_hybrid_functional_test.jl`](../test/interfaces/api_periodic_hybrid_functional_test.jl)
for the translated scope and
[`api_rigid_periodic_hybrid_functional_test.jl`](../test/interfaces/api_rigid_periodic_hybrid_functional_test.jl)
for the quarter-/half-turn rigid scope (24Tet4+6Pyramid5, volume1, actual
primary/P2 pairs, MSH4 transport, atomic non-rigid and direct-relation
rejections).

The batch fixture is
[`api_periodic_hybrid_batch_functional_test.jl`](../test/interfaces/api_periodic_hybrid_batch_functional_test.jl).
It generates two small unit Regions once, checks their independent volume and
exterior certificates, preserves lower ownership/cells, checks primary and P2
periodic query pairs, and verifies classified MSH4 transport. The default MSH4
writer saves the primary pairs; the live P2 query includes the quadratic pairs.
Missing copy events,
non-rigid and cross-Region relations reject without publishing a mesh.
Cross-Region relations are rejected by the per-Region volume certificate.
The complete actual event inventory is also checked against an intentionally
incomplete snapshot. This full fixture is opt-in; default tests gain no volume
generation.

A strictly interior Point, retained Curve chains and endpoint-only3–6-vertex
[planar sheets](hybrid_embedded_surfaces.md) have separate bounded embedded
contexts. Combining embeddings with multiple periodic Regions and general
shared periodic Faces remains outside this admission. Connected components
sharing Tri interfaces with uniquely owned exterior translated pairs are
implemented in the linked batch scope.
